# ✒️ Smart Scribe Notes

## ℹ️ Project Info

**Project Name**: Smart Scribe Notes
**Description**: AI-powered note-taking application with rich text editing, note management, AI enhancements, and secure note storage.

-----

## 🚀 How to Edit This Code

You can work with this project locally using your preferred IDE.

### Steps to Set Up Locally

1.  **Clone the repository**

    ```bash
    git clone https://github.com/JayrajsinhB/smart-scribe-notes-44.git
    ```

2.  **Navigate to the project directory**

    ```bash
    cd smart-scribe-notes-44
    ```

3.  **Install dependencies**

    ```bash
    npm install
    ```

4.  **Start the development server**

    ```bash
    npm run dev
    ```

### Edit and Commit Files

1.  Open the project in your preferred code editor.
2.  Make your changes and save the files.
3.  Commit your changes:
    ```bash
    git add .
    git commit -m "Your commit message"
    git push origin main
    ```
